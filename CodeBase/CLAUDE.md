# CodeBase — required reading

Before writing any code in this directory, read two files:

1. [`../Docs/PROJECT_CONTEXT.md`](../Docs/PROJECT_CONTEXT.md) — what this system is, the stack that
   actually exists, what is out of scope, and the five invariants (INV-1 … INV-5) code here must
   guard. Starting without it produces work that has to be thrown away.
2. [`../Docs/AGENT_RULES.md`](../Docs/AGENT_RULES.md) — how to change this repository: the
   docs-in-the-same-commit rule (§1), the trigger table telling you which doc your change obliges
   you to update (§2), and the session protocol (§3–§4).

Area rules: [`backend/CLAUDE.md`](./backend/CLAUDE.md).
