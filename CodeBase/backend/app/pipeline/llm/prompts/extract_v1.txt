You are extracting structured data from an OCR'd business document (invoice, purchase order, contract, or quotation).

Return a single JSON object that validates against the JSON Schema below (Draft 2020-12). Return ONLY the JSON object — no markdown code fences, no prose before or after it.

SCHEMA:
__SCHEMA_JSON__

Rules:
- Every field you include in "fields" must have "value", "confidence" (0.0-1.0), "verified" (always false — you cannot verify your own output, a separate deterministic check does that), and "source".
- "source" must be {"origin": "llm_inferred", "raw_text": "<the exact substring of OCR TEXT below that this value came from>"}. If you cannot quote exact supporting text, still set "origin" but omit "raw_text" rather than inventing one.
- If a field is not present in the document, omit it from "fields" entirely, or set "value": null with "confidence": 0.0. Never invent a value that is not supported by the OCR text.
- Do not infer a field's value from a different, nearby field. "mrc" (Monthly Recurring Charge) and
  "otc" (One-Time Charge) are common failure points: a one-time equipment invoice with no recurring
  billing has no "mrc" and no "otc", even though it has a "subtotal" and a "tax" — copying subtotal
  into mrc, or tax into otc, is wrong even if the numbers happen to be nearby on the page. The same
  applies to "billing_terms": do not fabricate it by copying "notes" or any other field's text.
- Money fields ("mrc", "otc", "subtotal", "tax", "total", and each line item's "unit_price"/"line_total") must be decimal strings with exactly two decimal places, e.g. "45000.00" — never "45,000", never "Rs. 45000/-", never a bare JSON number.
- "confidence" reflects how sure you are the OCR text was read correctly and assigned to the right field — not whether the value is correct. A separate deterministic check verifies correctness; do not inflate confidence to compensate for it.
- "document_type" is required and must be one of the values enumerated in the schema above.

EXAMPLE — a field that is genuinely absent from the document (e.g. "mrc" on a one-time invoice with
no recurring charge) must look exactly like this in "fields", with no "raw_text" key at all:
{
  "mrc": {
    "value": null,
    "confidence": 0.0,
    "verified": false,
    "source": {"origin": "llm_inferred"}
  }
}
Do not invent this field's value from "subtotal", "tax", or any other nearby number.
